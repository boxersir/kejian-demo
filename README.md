# 星栖课堂 · 裸眼 3D 沉浸式闯关课件（P0 Demo）

> 一份 3D 场景，四种裸眼立体模式，零硬件依赖进课堂。
> 课件：《太阳系的秘密》· 小学科学 六年级 · 3 关闯关 + 语音讲解 + 教师课堂报告

## 3. 四种裸眼立体模式（本产品的核心差异点）

| 模式 | 所需硬件 | 立体强度 | 目标场景 |
|---|---|---|---|
| **视差立体**（默认） | 无 | 中 | 所有设备保底方案，移动端最顺 |
| **红蓝眼镜** | 一副红蓝眼镜（约 1 元/副） | 强 | 全班每人一副，成本几乎为零 |
| **左右分屏** | 平行眼 / VR 盒子（约 20 元） | 最强 | 沉浸体验课、开放日 |
| **头部追踪** | 普通摄像头 | 强（穿窗感） | 班班通一体机（自带摄像头）。Demo 用鼠标模拟 |

> 关键商业价值：**同一套课件，学校有什么设备就跑什么模式**，不需要为了 3D 采购一体机。这是能进普通公立校的根本原因。

## 4. 技术栈（全部 MIT / Apache-2.0，商用无授权风险）

| 层 | 选型 | 许可 |
|---|---|---|
| UI | React 18 + Vite 5 | MIT |
| 3D | three.js 0.187（原生 API，未引入额外抽象层，保证老设备可控） | MIT |
| 状态 | Zustand 5 | MIT |
| 语音 | 浏览器原生 `SpeechSynthesis`（生产环境换 piper 预生成 mp3） | MIT / 浏览器内置 |
| 音效 | Web Audio API 实时合成（零素材、零版权） | — |
| 素材 | 全部程序化生成（行星贴图、星空、轨道） | 无第三方素材风险 |

**没有用任何付费/受限资源**：无外部模型文件、无第三方贴图、无音频素材包、无字体外链。

生产版追加（已在选型文档中定稿）：`piper`(MIT) 离线 TTS 批量预生成、`motion`(MIT) 动画、`lottie-web`(MIT) 奖励动效、`use-gesture`(MIT) 手势。

## 5. 性能红线实测（课堂老设备必须守住）

| 指标 | 红线 | 本 Demo 实测 | 结论 |

## 6. 自测命令与真实结果

```bash
cd demo

```

四个测试套件，全部通过：

```

tests/dom.test.mjs      生产包 DOM 挂载 / UI 结构 / 无 WebGL 降级     7/7  ✅
tests/offline.test.mjs  单文件离线包完整性 / 完全离线 / 降级         8/8  ✅
```

### 已修复的真实缺陷（自测发现，非纸面结论）

1. **无 WebGL 时整页白屏** —— 老设备/禁用硬件加速会直接崩溃整个 React 树。
   已加 `SceneBoundary` 错误边界：降级为提示层，右侧闯关面板与课堂报告继续可用。
   *这是公立校机房最容易踩的坑，必须提前堵住。*

2. **jsdom 下 `file://` 不自动执行内联脚本** —— 验证脚本已改为手动注入，确认离线包本身无问题。

### 未能完成的验证（如实标注）

- **真实浏览器截图/交互回归**（`tests/browser.test.mjs`）：本机 Chrome/Edge 进程被环境拦截（`Chrome.ProcessSingleton` 冲突，退出码 21），headless 与有界面模式均无法拉起，**截图与点击回归未取得证据**。
  替代验证：用 jsdom 真实挂载打包产物（含无 WebGL 路径）+ three.js 无 GPU 场景规格实测 + 离线单文件冒烟测试。
  在你本机执行 `npm run test:browser` 可产出 `demo/shots/*.png` 全流程截图。
